# 作业评价量规

## 检查维度

1. `结果`：是否满足明确需求和边界条件。
2. `推理`：能否解释关键步骤、数据流和取舍。
3. `测试`：是否运行最小相关测试，是否理解测试覆盖不到什么。
4. `帮助程度`：最高提示等级、共同编辑或参考答案使用情况。
5. `迁移`：是否能在新输入或新场景独立应用同一概念。

## 证据分类

- `independent`：学习者独立产出，关键推理可解释，没有使用 L4 内容。
- `assisted`：结果有价值，但使用了提示、共同修正或参考实现。
- `insufficient`：产物、运行证据或归属不够，不能可靠判断。

评价必须引用具体产物，保留最高提示等级，并把事实与建议分开。
