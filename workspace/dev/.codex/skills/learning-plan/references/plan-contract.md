# 学习计划契约

计划必须包含以下五个中文字段：

1. `学习目标`：具体到可观察的结果。
2. `成功证据`：最终独立产出、解释或修改能力，以及如何验证。
3. `阶段`：按先修关系组织，每阶段说明为什么现在学、需要哪些知识点和阶段成果。
4. `当前任务`：只有一个，能够在当前单次学习时长内完成。
5. `复习衔接`：列出与当前任务有关且已到期的复习，不超过五项。

## 调整规则

- 独立证据允许跳过或压缩已会内容。
- 辅助完成只能降低练习量，不能作为跳过先修的唯一证据。
- 重复误区或复习失败时回退到最小缺口，不整条路线重来。
- 项目目标变化时重算“必须理解、按需理解、暂不需要”三类概念。
