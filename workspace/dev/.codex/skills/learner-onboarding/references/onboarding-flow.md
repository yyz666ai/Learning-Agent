# 建档流程

## 最小必需信息

按顺序确认：

1. 当前最想完成的真实结果，而不是只问“想学哪门语言”。
2. Python、Go 或相关工程经验，以及信息来源是自述还是可观察证据。
3. 每周可投入时间、常见学习时段和希望的单次时长。
4. 偏好的讲解、练习和提示方式；默认采用分级提示。
5. 若目标是现有代码，确认仓库路径、希望看懂或修改的能力，以及只读边界。

## 提问规则

- 每轮只问一个最能改变后续路线的问题。
- 已由用户清楚说明的信息不重复询问。
- 能从允许读取的热状态确认的信息不询问。
- 必要时给一个不超过 10 分钟的小诊断任务；诊断失败不是评价，只用于选择起点。

## 确认摘要

保存前列出：主目标、成功标准、当前证据、时间预算、偏好、项目边界和仍未知信息。只有用户明确表示确认后才写入。
