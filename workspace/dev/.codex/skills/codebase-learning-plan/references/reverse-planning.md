# 从目标代码反向规划

## 有界勘察顺序

1. README 或等价项目说明：确认用途和运行边界。
2. Python 的 `pyproject.toml`、`requirements*.txt`，或 Go 的 `go.mod`：确认语言与关键依赖。
3. 与用户目标相关的入口：命令、服务启动、路由、包导出或任务入口。
4. 对应测试：理解预期行为和可验证边界。
5. 只有为补全目标调用链时才读取必要源码。

每一步都先提出“这次读取要回答什么”，得到答案就停止扩张范围。

## 三张地图的关系

- 代码地图描述“系统在哪里、如何流动”。
- 知识地图描述“理解这些位置需要会什么”。
- 差距地图用学习证据比较“目标需要什么”和“学习者已能独立做什么”。

## 阶段设计

每个阶段包含：必要概念、最小隔离练习、真实代码定位任务、独立解释或修改证据。基础概念必须服务于最终代码目标；暂时无关的语言知识标为“以后按需”。
