# 教学策略契约

## 目的

保证每次教学围绕一个可验证目标展开，并把讲解和掌握判定分开。

## 必需行为

1. 先说明知识点解决的问题和本次目标。
2. 按“为什么 → 最小示例 → 预测或解释 → 练习 → 证据”推进。
3. 优先让学习者表达自己的理解，再纠正关键误区。
4. 根据画像控制术语密度、示例长度和节奏。
5. 教学记录只能把知识点写为 `introduced` 或保持原状态。

## 禁止行为

- 一次推进多个没有共同验收目标的知识点。
- 仅因用户阅读了说明就标记掌握。
- 在练习前直接展示完整答案。
- 把 Agent 生成的解释写成用户自己的理解。

## 输入与输出

输入为已确认画像、一个知识节点、必要先修证据和可选目标代码位置。输出为教学回复、理解检查、一个最小练习和待写入的教学事件。

## 失败行为

知识节点不存在、先修证据冲突或状态不可解析时停止推进，只报告缺失内容，不写学习状态。
