## 讲义内容

### 1. Go 工具链是什么

**Go 工具链**，就是装 Go 时一整套帮你「写代码 → 跑起来」的工具，装完 Go 它就在你电脑里了。

它里面有几个你马上会用到的主角：

- `go run`：把你的代码跑起来（执行程序）；
- `go version`：报告你装的 Go 是哪个版本；
- 另外还有编译、管理依赖等工具，现在先不用管。

为什么要先学会验证？因为只有确认「工具链真的装好了」，后面写代码、跑程序才不会一上来就报「找不到命令」的错。

**本页请做**：打开电脑的终端（macOS 叫“终端”，Windows 叫“PowerShell”或“终端”），输入下面这条命令并回车，看看有没有显示版本号：

```bash
go version
```

### 2. 验证装好了吗

你刚在终端敲了 `go version`。

想一下：如果 Go 工具链装好了，屏幕上应该出现什么？

- 出现 `go version go1.x.x ...` 这样的版本号 → 装好了，可以放心往下走；
- 出现 `command not found` 或 `不是内部或外部命令` → 还没装好，去 Go 官网（golang.org/dl）下载安装包，装完重新打开终端再试一次。

### 3. 一个 Go 程序的最小结构

任何 Go 程序，都至少要有两行「地基」：

```go
package main

func main() {
    // 你要做的事，写在这里面
}
```

- 第 1 行 `package main`：声明这是一个可以独立运行的程序（以后你见到别的 package，先记住“能直接跑的 Go 程序都叫 main”）；
- `func main()`：**main 函数**，它就是程序的大门——电脑执行你的程序时，一定从 `main()` 函数的第一行开始。

再看怎么跑：在终端输入 `go run main.go`，Go 就会编译并执行这个文件，程序从 `main` 函数开始跑。


### 4. 跑起第一个程序

把下面这段代码完整敲进你的 `main.go`（别复制粘贴，自己敲一遍记得更牢）：

```go
package main // 声明：这是一个能独立运行的程序

import (
    "fmt"  // 引入 fmt 包，它负责“把文字打印到屏幕上”
    "time" // 引入 time 包，用来取当前时间
)

func main() { // main 是入口函数，程序从这里开始执行
    name := "小明"                  // 把名字存进变量 name（:= 表示“新建一个变量并放值进去”）
    today := time.Now().Format("2006-01-02") // 取今天日期，并格式化成 年-月-日
    fmt.Println("你好，" + name + "！今天是 " + today) // 把问候语打印出来
}
```

看不懂没关系，先记住三件事：程序从 `main` 开始、`fmt.Println` 负责打印、`go run main.go` 负责运行。

然后在终端（先 `cd` 进 projects/go/package-main 这个文件夹）运行：

```bash
go run main.go
```

看到一行「你好，小明！今天是 2026-08-23」之类的输出，你就跑通了！
