# NumPy / Pandas（数据处理）

## 是什么
Python 数据处理的基石：NumPy 管数组与数值计算，Pandas 管表格数据（读、洗、查、算）。

## 前置
- Python：list、dict、循环（`python.collections`、`python.control-flow`）

## 学什么（路线骨架）
1. NumPy：ndarray、索引、广播、向量化
2. Pandas：Series / DataFrame
3. 读写 CSV/Excel、缺失值处理
4. 筛选、分组、聚合
5. 与 JSON/文件结合的小型数据分析
