# Gin（Go Web 框架）

## 是什么
Go 最常用的 HTTP Web 框架，路由 + 中间件 + JSON 处理都很顺手。学它 = 学会用 Go 写 Web 服务。

## 前置
- Go：函数、struct、interface、error（`go.functions`、`go.structs-methods`、`go.interfaces`、`go.errors-defer`）
- HTTP 概念（`go.http`）

## 学什么（路线骨架）
1. 路由与 Handler
2. 参数绑定与 JSON 响应
3. 中间件
4. 错误处理
5. 分组路由与项目结构
