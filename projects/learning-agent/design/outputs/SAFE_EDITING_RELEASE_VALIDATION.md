## 2. 已实现行为

- 默认只读仍可答题、翻页和选文提问；编辑当前页标题、Markdown 和教学代码时保留草稿，预览后保存，取消不应用。
- 七种正文工具为 H1/H2/H3、加粗、斜体、高亮、下划线；代码单独编辑。题干／选项／答案不能通过普通编辑绕过校验。
- AI 修订及追加练习遵循提议→确认生成→候选差异→确认应用／取消。模型返回候选不等于写入当前课件，生成词和应用词按阶段区分。
- 普通答疑和候选模型调用显式使用只读运行模式；最终写入由后端检查项目、课件与基线版本后执行。旧手动重做和课件追加入口不能绕过确认。
- manifest 与私有答案配对保存，Markdown 从同版本确定性生成；全部完成后切换当前指针。导出带 revision 与页面 ID，不导出私有判题键／解析。
- 历史恢复生成新的恢复版本，不删除历史；旧 JSON 先保存原始基线，兼容升级另存版本，原始旧代码也可恢复。
- 用户代码和历史作答保留；变题不沿用旧通过状态或旧题解析。题库读写与课件事务共用用户锁，回滚不吞掉并发作答。
- 章节总课次、单次分钟、课外练习、分次安排独立表示；不按知识点数量累加章节预算，也不把整章多次课说成一节课。教学规则要求目标、先修、实践与验收有对应关系；自由浏览不等于掌握。

## 6. 已知边界与发布门槛

- 当前用户锁是单服务进程内互斥，不承诺多 worker、多实例或分布式运行安全。
- 候选生成目前是同步请求；初始 Plan／lesson 后台生成的短轮询特性不能套用到所有编辑请求。反向代理需单独配置足够超时。
- 只读参数和实际候选生成已验证到所述范围，不宣称跨平台所有运行时的恶意写入／崩溃情形均已实验认证。
- 记录持久化与异常恢复有自动化覆盖，不等于所有断电、磁盘损坏和多进程崩溃场景都已验证。
- 本科系统学习、临考复习、读现有仓库、自带题单／技术栈、其他领域及长期掌握尚无本报告的完整端到端验收。
- 不保证所有自然语言识别、未来模型输出或所有教学内容永远正确；格式校验通过与教学质量合格分别判断。
- API Key、userdir、隔离模型原始输出、浏览器本地数据和本机 `.agents/` 不在本次提交范围。保留测试源代码与评测报告，便于复现；不能把未上传的模型原始输出说成公开可复现数据集。
