# 课件生成与课堂工作区修复记录

日期：2026-08-31。此记录区分真实模型测试、自动化回归和未验证范围，不承诺所有后续模型输出都必定成功。

## 结论：这次不是 Windows 启动适配故障

本机 macOS 日志在 08:12 显示模型已正常返回：耗时 35.34 秒、工具调用 0、流错误 0、进程退出码 0。随后 Python 覆盖校验拒绝了 `Proxy 代理`；自动修正后又拒绝 `track / trigger 依赖收集`。

这和 Windows 找不到 Codex、虚拟环境位于 `Scripts` 的启动问题不是同一层。当前启动兼容回归仍在测试集中，但本次没有 Windows 真机端到端测试。

## 根因与修改

1. **技术标题被当成必须连续出现的短语。** 现在把显式的 `Proxy 代理` 拆成 `Proxy`、`代理`；`track / trigger 依赖收集` 拆成三个必须覆盖的词组；斜杠列举的 `shallowRef / shallowReactive` 分别检查。不是按 Vue 主题硬编码放行。
2. **修正一次只看到第一个覆盖错误。** 现在汇总本章所有词面覆盖缺口，一次交给唯一的模型修正调用。
3. **提示与校验标准不一致。** 原提示强调“引用页合起来覆盖”，实际还要求至少两页各有匹配内容。现在原始生成提示、失败说明和修正提示使用一致规则。纯中文词组仍按词面检查，不能把它宣称为语义判卷器。
4. **练习文件名不一致。** JavaScript 作业实际创建 `main.js`，与课件说明对应；已有练习文件不覆盖、不清空。

仍保留：真实页面 ID、至少两个不同页面、引用原文核对、知识点集合一致性、所有词组覆盖、技术标识符边界。`contract` 不算 `track`，仅标题点名不算正文教学。没有关闭校验，也没有把用户旧的失败输出强行存成成功课件。

## 界面

- PPT 右上角锁／铅笔切换只读和编辑；撤销为小图标。图标具有鼠标提示和可访问名称。
- 关闭 PPT 只改变布局；保留左侧大纲、计划和紧凑项目入口，聊天区域扩展。
- 点击聊天栏的“打开课件”恢复同一页面，未保存草稿仍保留；不重新 onboarding，不调用模型。
- 版本记录、Markdown 导出、Bug 报告导出集中到左下角设置。
- 移动端导航抽屉保留大纲入口。

## Bug 报告的范围与隐私

设置中的导出下载本地 JSON，不自动上传。接口为 `GET /api/support/bug-report?user_id=...`。

它包含操作系统/Python 版本及本功能启用后记录的最近 Plan、课件生成结果、分类、规则代号和时间。不包含 API Key、账户资料、用户画像、对话、完整模型输出、文件路径或整份运行日志。下载时再次校验白名单，损坏记录会被忽略。它不是身份认证功能；本项目仍按本机自用模式运行。

该记录不是项目内容快照，也不会假装已经补录旧故障。新功能启用前的失败需要另查本机服务日志。写诊断文件失败不会把已成功生成的课程变成失败。

## 真实模型测试：包含失败，不只展示成功

测试均使用隔离合成画像、已确认的课程大纲和项目配置的 Codex → DeepSeek Flash 链路，不覆盖真实用户目录。

| 场景 | 结果 | 耗时 | 模型调用 | 说明 |
| --- | --- | ---: | ---: | --- |
| Vue 6 知识点 | 19 页生成、保存、重载通过 | 74.73 秒 | 2 | 首次 44.16 秒；一次代码骨架修正 30.42 秒 |
| 原问题同款 9 知识点，提示统一前 | 失败，已保留证据 | 85.67 秒 | 2 | 修正后仍因“解构失响应”逐页词面覆盖失败 |
| 相同 9 知识点，提示统一后 | 24 页生成、保存、重载通过 | 129.96 秒 | 2 | 首次 58.70 秒；修正 71.22 秒，期间一次流错误恢复 |

最后一轮包含 6 道课堂选择题、1 个课后作业、3 项面试问答。9 个覆盖项包括 ref、reactive、Proxy、track/trigger、computed、watchEffect、浅层响应式、解构失响应、代理相等性。两轮成功测试均为工具调用 0、思考输出 tokens 0。

这些耗时是单次样本，不是 SLA，也不是分位数统计。已关闭思考和工具调用不等于零延迟：几千输出 tokens、完整课件修正和连接恢复仍会耗时。

原始测试证据只保存在被 Git 忽略的 `evals/runs/`，不随开源仓库上传。真实用户旧输出只读回放发现了额外词面缺口；没有重新发布旧内容。

## 本机验收操作

1. 刷新原页面，保留原项目；失败课件点“重新生成课程”。无需重做学习目标。
2. 打开一页，切到编辑，输入少量文字但不保存。
3. 收起 PPT：确认大纲仍在；点“打开课件”，确认原页与草稿仍在。
4. 切回只读：应出现放弃未保存修改的确认；取消应继续保留草稿。
5. 打开左下角设置：检查版本记录、Markdown、Bug 报告入口。
