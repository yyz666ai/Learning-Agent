# Learning Agent 中英文模式设计

日期：2026-08-31
状态：用户已确认产品方向；本文待书面设计复核，尚未实施。

## 1. 已确认需求与范围

- 默认中文，不根据浏览器语言自动改为英文。
- 页面右上角增加地球图标，点击打开语言菜单：中文、English；当前语言带选中标记。
- 引导页面、课堂页面、收起 PPT 后均能访问该入口，不挤占课件编辑按钮。
- 切换后界面立即更新，后续生成的内容遵循选择的语言。
- 历史内容保留原版，允许按需生成翻译副本；切换语言本身不调用模型、不重做课程、不覆盖学习进度。
- 本次不改云端账户体系、收费、服务器部署，不购买服务器、不发布营销内容。

## 2. 方案选择

选择统一语言上下文：前端翻译词典 + 用户语言偏好 + 后端生成与审阅语言约束。

不采用仅翻译按钮的方案：无法覆盖生成内容，还会撞上现有中文注释校验。
不采用整站自动翻译或切换时整课重做的方案：存在额外模型成本、答案状态错位及覆盖用户修改的风险。

## 3. 当前代码风险

- frontend/index.html 与 frontend/js 中存在静态、动态中文界面文案。
- backend/lesson_generator.py 的代码注释检查、修复提示与旧数据补全逻辑固定使用中文。
- backend/lesson_review.py 的审阅反馈提示指定中文。
- 现有 language 字段表示 Go、JavaScript 等编程语言，不能改作界面语言。
- Plan 的文本解析及知识库缓存必须检查是否依赖中文标题或遗漏语言维度。

## 4. 前端交互

使用现有图标风格的地球图标，不用 emoji。菜单提供键盘导航、Escape 关闭、点击外部关闭与本地化无障碍标签。

建立集中词典与 t(key, params) 接口，翻译静态文字、动态状态、错误、按钮、提示、title、aria-label、占位符及日期/数量展示。设置 document.lang 与标题。

范围涵盖 onboarding、诊断题框架、Plan 窗口、课件导航/编辑/版本记录、引用提问、题库/复习/作业、项目管理、设置与错误反馈。

禁止扫描 DOM 后机器替换中文：用户输入、项目名称、代码、文件路径、历史回答、知识内容不是界面词典。
生成状态应返回稳定阶段码与参数，由界面翻译；历史原始异常仅作为诊断信息，不直接变成英文模式下的中文提示。

## 5. 状态与持久化

新增独立 locale 字段，允许 zh-CN、en；旧数据缺失时默认为 zh-CN。
用户偏好保存在 userdir/u_<id>/preferences.json，原子更新并保留其他设置；浏览器仅做按用户区分的启动缓存。

读取用户偏好后更新界面。保存失败时明确提示“本次已切换，但偏好尚未保存”，保留重试能力，不宣称已持久化。
切换学习项目不改变用户语言偏好。

每个模型请求和后台任务在创建时保存 locale 快照；任务完成时保留该语言元数据。切换不取消旧任务、不把旧结果错误标记为新语言。
旧语言任务完成后显示可理解的语言提示，由用户选择查看原结果或请求翻译，不自动重复生成。

## 6. 生成、Skills 与校验

在通用生成上下文中加入目标语言，再传到所有模型入口：意图判断、动态提问/选项、诊断、Plan、课件、讲解、修改提案、追加练习、答案反馈、模拟面试与审阅。

Skills 保留教学策略；去掉与可选语言冲突的“必须中文”要求，明确以请求 locale 为准。无需复制两套完整 Skills。
结构字段名、枚举、编程语言、页 ID、题目 ID、选项 ID 与答案引用不翻译。
英文模式下标题、正文、讲解、注释与用户可见反馈采用英文；专有名词、引用原文、用户要求逐字保留的内容允许例外。

结构检查继续验证必填字段、代码块、选项与答案引用完整性；注释检查按内容语言调整，不能再以出现汉字作为英文课件通过条件。
内容覆盖继续由语义审阅判断，不退回标题/关键词匹配。
语言要求并入已有生成和审阅请求，不为每个界面切换额外增加模型调用。

Plan 内部尽量使用稳定结构字段，Markdown 负责呈现。对旧中文 Plan 保留兼容；新英文 Plan 不能依赖中文章节标题才可读取。

## 7. 知识库与缓存

检索仍以学习目标、基础、技术栈和知识点匹配，语言不是改变课程主题的理由。
中文知识来源可以作为生成英文课程的参考，但缓存成品不能直接以英文结果返回。
成品缓存和翻译缓存加入 locale；翻译缓存同时包含原版 ID、原版内容哈希与翻译版本。
历史无 locale 成品按旧中文默认处理，不修改原始文件。不同语言不能互相覆盖。

## 8. 历史内容翻译副本

在完整 Plan 和课件相关操作中提供“翻译为当前语言”，不弹出整门课程重生成。
用户确认目标范围与语言后，以后台任务生成译本；默认仅当前 Plan 或当前章课件，绝不自动扩展至其他章节。

译本记录源版本、源内容哈希、目标语言、创建时间，作为独立展示变体保存，不更换课程身份。
题目/选项/页 ID、正确答案引用与既有作答状态保持不变；代码可执行内容、用户代码、路径及命令不翻译，教学注释可以翻译。
翻译不得新增教学要求或改变题意；保存前校验结构、引用及翻译语义。失败保留原版并展示可重试原因。
原文被编辑后旧译本标记过期，不自动替换；重新翻译仍需用户确认。
不批量翻译历史聊天、用户笔记或用户提交的资料。新答疑可用当前语言解释这些原始内容。

## 9. 测试与验收

1. 新用户默认中文；地球菜单选择英文，所有界面框架立即英文；切回中文正常。
2. 刷新、重新启动、项目切换后偏好正确；不同用户不串语言，保存失败提示真实。
3. 两种语言分别走初学、精进、面试场景：自由输入、动态选择题、诊断、Plan 确认、首章课件、作业和右侧答疑。
4. 英文 Plan 可解析为大纲；英文代码注释可通过校验；缺少真实教学内容仍被语义审阅拦截。
5. 修改课件、追加练习、复习反馈、模拟面试遵循请求语言；不翻译内部 ID 和答案值。
6. 生成中切换、并行请求、重试、恢复页面不导致语言串用或重复生成。
7. 中英文成品缓存隔离；中文缓存不可直接冒充英文结果。
8. 原版翻译只作用于所选范围，进度和答案不丢失；取消、失败、原文变动及译本过期可恢复。
9. 桌面与窄屏验证菜单、长英文按钮、PPT 收起/展开、键盘可用性和布局；不影响 Mac/Windows 的启动与文件夹操作。
10. 运行原有回归测试，记录真实模型调用的结果和耗时；模拟测试、实际模型测试及平台实测分开报告，不承诺绝不失败。

## 10. 实施边界与交付

设计复核通过后进入实施计划，再按测试先行修改；所有改动在现有 main 上进行，不创建新分支、不纳入用户未跟踪的 .agents/。
完成时列明已覆盖的界面与模型入口、执行的测试、未实测平台和残留风险。未完成前不宣称英文模式已上线。
