# 统一练习题库与专注学习界面设计

## 目标

学习界面只保留大纲、课堂讲义、练习题库和对话；学习项目切换与完整 Plan 收入设置。课堂选择题、错题、课后作业与面试题进入同一个可持久化的练习题库。

## 已确认产品决策

- 采用独立 `practice-bank` 记录层，不把课堂题硬塞入面试题源文件。
- 面试题保留现有扩展讲解与 Anki 评级能力，由统一读取端点合并展示。
- 课堂选择题第一次展示时入库，每次作答后更新答题次数、错误次数、最近结果和是否待复习。
- 课后作业在课程生成成功后立即入库，初始状态为“待完成”。
- 学习态左栏不显示学习项目和 Plan dock；项目切换、添加、删除与完整 Plan 全部放在“设置与档案”。Onboarding 首页仍显示历史项目。

## 交互与视觉

### 生成进度

等待卡同时显示：当前阶段说明、已完成百分比、剩余百分比、已等待时间和预估剩余时间。进度是基于同类历史耗时的估算，未完成前不超过 92%。

### Markdown 与教学重点

- Markdown 支持 1–6 级标题，`####` 不再作为普通字符显示。
- fenced code 使用深色代码框、语言标签、语法高亮与复制反馈。
- `**重点**` 渲染粗体，`==易错点==` 渲染低饱和黄色高亮。
- 课程生成合同要求每页最多突出 2–4 个重点，避免整页全部加粗。

### 左栏

- 品牌栏高度从 64px 收紧到 48px。
- 大纲/题库 tab 和分页控件缩小外框，文字提高一档。
- 可滚动大纲占用所有剩余空间。
- “题库”改名“练习题库”，显示所有课堂题、作业和面试题；错题使用文字与颜色双重标记。

## Go 知识库

新增指针基础、指针参数/返回值、值与指针接收器、函数类型/函数值、闭包与回调。教学中明确 Go 没有 C/C++ 式指针运算和传统“函数指针”，Go 的对应机制是函数值和函数类型。

## Onboarding Plan 触发条件

意图识别使用多轮 slot filling，但不追求把所有槽位填满。`topic` 和 `desired_outcome` 是 Plan 的必需槽位；其他槽位只有在会改变路线、课程深度或项目结构时才追问。

## 验收

- 左栏不再显示学习项目或 Plan dock，设置中可查看与切换。
- Plan 的 4–6 级标题正确渲染。
- 课堂代码围栏显示为代码框并可复制。
- 等待卡显示当前工作、完成/剩余百分比和预估时间。
- 做过一道课堂题后题库总数立即增加；错题显示待复习，重做正确后更新为已掌握。
- 每章课后作业在课程准备完成后出现在练习题库。
- Go 基础路线包含指针、函数值、闭包与回调。
