# 课件语义审阅修复方案

用户已确认：知识点覆盖交给大模型判断，不再正则拆标题、用词面匹配拦截课件。

## 边界与取舍

采用独立、只读的模型审阅，而非生成者自报覆盖，也不直接取消教学质量检查。后台提供本章原始知识点、学习目标、学习者基础以及整份当前课件的正文、代码、题目。只发一次批量审阅请求，不逐知识点调用工具或上网。

代码负责页面与答案的结构安全；模型负责解释是否达成学习目标。允许同义表达、一页覆盖、多知识点共用页面；不要求标题原词出现或固定两页。审阅结果逐知识点返回 covered/missing/uncertain、理由和真实页面引用。引用 ID 的真实性由代码校验，但不再匹配教学关键词。

missing 不发布不完整课件，说明具体漏讲点；uncertain、调用超时或不合法审阅结果显示审阅未完成，不能伪装结构错误。语义审阅失败不触发整份模型重写。原已保存版本保持不变。一次生成通常增加一次只读审阅调用，实测耗时单独记录，不承诺零开销。

本次不修改 Plan 或右侧编辑范围；范围收窄是独立问题，不能宣称本次已经解决。
