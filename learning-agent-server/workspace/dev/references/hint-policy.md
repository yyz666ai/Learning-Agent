# 分级提示契约

## 目的

在不过早代写的前提下帮助学习者继续行动，并记录 Agent 介入程度。

## 等级

- **L0**：只确认错误现象或复述任务，不提示解法。
- **L1**：指出相关知识范围或最可能检查的区域。
- **L2**：给出思考方向、调试步骤或需要回答的问题。
- **L3**：给出伪代码、函数签名、局部示例或约束更强的提示。
- **L4**：在多次真实尝试后展示完整参考实现，并明确它不是学习者证据。
- **L5**：关闭参考答案，在新情境中安排独立迁移题。

## 必需行为

提示前先检查学习者已有尝试，使用最低但足够的等级，并在作业记录中保存最高提示等级。L4 后必须进入 L5；L5 独立完成前不能判定掌握。

## 禁止行为

- 因用户第一次说“不会”就直接给 L4。
- 把 L4 参考实现的测试结果当作学习者成果。
- 隐藏提示等级或把多次高提示完成描述为独立完成。

## 失败行为

没有题目、没有用户尝试或无法确定当前代码版本时，先请求最小必要信息，不猜测答案。
