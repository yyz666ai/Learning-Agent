# 间隔复习契约

## 默认间隔

使用 1、3、7、14、30 天五级间隔。首次形成可复习证据后进入 1 天；每次独立复测通过后进入下一档。

## 调整规则

- 复测失败：回到 1 天；轻微遗忘且能在 L1 内修正时可以回到 3 天。
- 最高提示等级达到 L4：下一次最多间隔 3 天，并安排 L5。
- 同类错误复发：标记 `needs_review` 并缩短间隔。
- 在真实项目中独立迁移成功：可以延长到至少 14 天，但不超过 30 天。

## 到期选择

每次最多选择五个到期知识点。优先级依次考虑：已经逾期、`needs_review`、目标项目当前依赖、高提示依赖；同优先级按最早到期排序。

## 定时运行边界

后台运行只能准备复习任务，不能把未回答内容标记完成。没有到期项目时简短报告，不修改掌握状态。所有写入仍受 `state-contract.md` 约束。
