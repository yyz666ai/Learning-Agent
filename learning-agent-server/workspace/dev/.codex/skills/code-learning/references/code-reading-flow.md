# 有界代码阅读流程

## 1. 定位

写清文件、符号和本轮问题。先看直接定义和对应测试；只有解释缺口确实需要时才沿调用者或被调用者扩展一层。

## 2. 责任与边界

用一句话说明代码负责什么、不负责什么。列出输入、输出、错误和可观察副作用。

## 3. 执行追踪

选择一个代表性输入，让学习者先预测，再逐步追踪状态变化、分支和返回值。

## 4. 两层解释

- 语言基础层：Python 或 Go 的语法、类型、控制流、错误、并发等必要概念。
- 项目决策层：为什么该仓库这样组织、依赖什么约定、替代方案是什么。

不要把项目习惯误说成语言规则。

## 5. 迁移

改变输入、顺序、错误条件或小型需求，让学习者独立预测或写一个隔离版本。评价工作交给作业批改流程。
