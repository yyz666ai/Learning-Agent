# 进度汇报契约

## 固定栏目

- `独立完成`：只列有 independent 证据的能力。
- `辅助完成`：列出完成结果和最高提示等级，不与独立完成合并。
- `待复习`：只列已到期或即将到期的相关项目，并标明日期。
- `重复误区`：至少有两次证据指向同一误区才列出。
- `推荐下一步`：只推荐一个动作，说明它与目标和当前证据的关系。

## 禁止推断

- 不根据学习时长换算掌握百分比。
- 不根据课程读完、复制成功或测试通过推断掌握。
- 空画像或空证据应如实报告“尚无可确认的学习证据”。
- JSON 无法解析、schema 不匹配或 revision 冲突时，不使用可疑数据作结论。
