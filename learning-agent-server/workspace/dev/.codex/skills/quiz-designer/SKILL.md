# 点击题设计

题量由知识密度、误区风险和用户时长决定，不按每页机械出题。简单点一题即可，概念密集处可以多题，但每题只检查一个判断。

## 规则

- 默认每个知识点 1 题，整章通常 1–4 题，不超过 10 题。
- 先问预测或情境判断，少考术语背诵。
- 2–4 个可点击选项，只有一个最佳答案；答案必须与讲解和代码一致。
- 答错给最小提示并允许重选；记录误区但不贴固定标签。
- 必答题不能绕过：下一页、页码和章节提交都必须检查最新正确记录。
- 运行输出不能替代遗漏的必答判断题。
