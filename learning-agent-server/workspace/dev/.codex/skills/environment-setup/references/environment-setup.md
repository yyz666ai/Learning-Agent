# 零基础环境准备页参考

只展示当前课程实际需要的软件与步骤；不要把这份参考原样全部塞进一张 PPT。

## 页面顺序

1. **你要准备什么**：列出必装工具及用途，可选编辑器单独标记。
2. **从哪里下载**：只给官方入口或本次研究已经核验的官方文档。
3. **怎么确认装好了**：给版本验证命令和成功示例，不把示例版本号写成硬要求。
4. **课程代码放哪里**：显示系统实际创建的课程项目目录和源文件名。
5. **第一次怎么运行**：给与真实文件名一致的最小运行命令。

## 常用官方入口

| 工具 | 官方入口 | 常用版本验证 |
|---|---|---|
| Go | https://go.dev/dl/ | `go version` |
| Python | https://www.python.org/downloads/ | macOS/Linux 常用 `python3 --version`；Windows 根据安装方式使用 `py --version` 或 `python --version` |
| Visual Studio Code | https://code.visualstudio.com/Download | 打开应用即可；CLI 是否可用不是课程门禁 |

其他语言、框架、包管理器和编辑器必须从当前课程研究证据中取得官方入口，不能凭记忆拼 URL。

## 平台表达规则

- 已知操作系统：只显示该系统的步骤。
- 未知操作系统：分成 macOS、Windows、Linux 三个紧凑小节，每个小节只保留安装入口、验证命令和常见差异。
- 不把 Homebrew、Chocolatey、winget、apt 等第三方包管理器当作唯一方案；如果使用，标明它是可选安装方式。
- 环境变量、权限、代理或镜像问题只有真实发生时再展开，不在第一张环境页制造额外负担。

## 完成证据

只有版本验证命令成功，且课程的最小源文件能从课程项目目录运行，才写入 `environment_ready`。该状态只证明工具链可用，不代表任何编程知识已经掌握。
