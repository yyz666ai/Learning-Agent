# LangChain（LLM 应用编排）

## 是什么
把大模型调用、提示词、检索、工具串成一条可复用链路的 Python 库。学它 = 学会「把 LLM 变成能干活的应用」。

## 前置
- Python 基础：函数、类、模块（`python.functions`、`python.objects-types`、`python.modules`）
- 一点 HTTP/API 概念（`python.web`）

## 学什么（路线骨架）
1. 模型调用与 Prompt 模板
2. Chain / Runnable 组合
3. 工具（Tools）与函数调用
4. RAG：文档加载 → 切分 → 向量化 → 检索
5. 输出解析与结构化
6. 记忆与多轮
