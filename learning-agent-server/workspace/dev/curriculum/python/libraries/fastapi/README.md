# FastAPI（Web API 框架）

## 是什么
用 Python 快速写 HTTP 接口的现代框架，自带类型校验、自动文档。学它 = 学会「写一个能被别人调用的后端服务」。

## 前置
- Python：函数、类型标注、类（`python.functions`、`python.objects-types`）
- HTTP 基础（`python.web`）

## 学什么（路线骨架）
1. 路由与请求/响应
2. 路径/查询/请求体参数 + Pydantic 校验
3. 依赖注入
4. 错误处理与中间件
5. 测试（TestClient）
