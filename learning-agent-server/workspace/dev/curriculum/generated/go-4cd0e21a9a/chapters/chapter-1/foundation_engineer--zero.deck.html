本章目标

为什么需要“三件套”

一个 Go 程序要能运行，就像开一家小店要先备好三样东西： - **package main** = 门牌：告诉 Go「这是一家可以直接开门的店」，也就是可以运行的程序。 - **import "fmt"** = 工具箱：把「打印文字」这个工具借进来用。 - **func main()** = 开门流程：程序启动后，从这一段开始干活。 缺了门牌，Go 不知道这是不是能运行的程序；缺了工具箱，想说话没有工具；缺了开门流程，程序不知道从哪开始。三件套缺一不可。 **本页请做**：读一遍，在心里记住三件套的名字和作用，下一页看它们的真身。

最小骨架

先看两件套的骨架

这是「能启动但还不会说话」的骨架，先认识两件套：`package main` 和 `func main()`。`import "fmt"` 和打印功能，下一页再加。 **本页请做**：读注释，数一数这个程序里有哪两件套；先不要运行，下一页会给出完整程序。

package main // 第 1 件套：告诉 Go 这是一个可以运行的程序包

func main() { // 第 2 件套：程序启动后，从这里开始执行
    // 里面先空着：程序能启动，但屏幕上什么也看不到
}

最小完整程序

三件套凑齐：最小完整程序

把三件套凑齐，程序就会开口说话： - `import "fmt"` 把打印工具箱搬进来； - `fmt.Println("Hello, 世界!")` 从工具箱里拿出喇叭，把这句话喊到屏幕上，喊完自动换行。 这就是 Go 的「最小完整程序」：任何 Go 程序都从这里长出来。 **本页请做**：对照注释，把每一行的作用在心里讲一遍；记住这个程序的样貌，后面的练习要自己写一个类似的。

package main // 告诉 Go：这是可以运行的程序包（三件套之一）

import "fmt" // 借入 fmt 工具箱，里面装着打印用的 Println（三件套之二）

func main() { // 程序启动后从这里开始执行（三件套之三）
    fmt.Println("Hello, 世界!") // 把括号里的文字打印到屏幕上，并自动换行
}

两种运行方式

怎么让程序跑起来：go run 与 go build

程序写好以后，有两条路让它跑起来： - **go run main.go**：临时演出。直接运行，看完就走，不留下任何文件。适合一边写一边试。 - **go build -o hello main.go**：打包带走。生成一个叫 `hello` 的可执行文件，之后随时用 `./hello` 运行。适合做出能交付的程序。 可以这样记：`go run` 是当场试吃，`go build` 是把菜装盒打包，`./hello` 是打开盒子吃。 **本页请做**：对照下面命令，把「哪个命令生成文件、哪个直接运行」记清楚；下一页做一道判断。

go version                # 先确认电脑里装好了 Go（会显示版本号）
go run main.go            # 直接运行 main.go，不产生文件
go build -o hello main.go # 把 main.go 打包成可执行文件 hello
./hello                   # 运行刚生成的可执行文件 hello

打印与换行

fmt.Println：打印一行并自动换行

`fmt.Println` 的名字拆开看：Print = 打印，ln = line（一行）。所以它喊完一句话，会**自动换行**。 下面的程序连着喊两句，猜猜屏幕上会是几行？ **本页请做**：先在心里预测输出——会看到几行、每行是什么；记住 Println 会自动换行。

package main // 告诉 Go：这是可运行的程序包

import "fmt" // 借入打印工具箱

func main() { // 程序从这里开始
    fmt.Println("第一句") // 打印「第一句」，然后自动换行
    fmt.Println("第二句") // 打印「第二句」，再换行
}
