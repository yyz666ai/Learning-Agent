## 发现与修正

1. 自动评分最初把“服务员”“下订单/收货”“打电话/发邮件”误判为没有类比，已扩充可解释的类比词表；人工检查确认回答本身生动。
2. 项目交付首轮出现未检查环境就建议全局安装依赖的问题。这是真问题，不是评分误差。现已在已确认画像的教学提示中禁止另造目录和全局安装，并完成第二次真实调用复测。
3. 七条路线均未重复询问基础；零基础 1 步进入教学，有基础者均在 3–4 道点击题后、最多 2 步进入教学。

原始结果保存在 `evals/runs/phase-c-real/`；项目交付修复后的复测保存在 `evals/runs/phase-c-project-fix/`。
