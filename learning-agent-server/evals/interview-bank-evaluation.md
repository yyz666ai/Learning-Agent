## 测评方法

每个画像都执行真实流程，而不是只检查提示词：

1. 提交用户目标、基础、每日时长和学习路线。
2. 对非零基础用户完成 3–4 道可点击诊断题。
3. 确认画像并验证 `plan.md` 确实写入该用户目录。
4. 发出第一条学习请求并收集完整流式回复。
5. 检查是否在 1–2 步内开课、是否重复摸底、是否泄露内部流程、是否有生动类比、是否贴合路线、是否一次塞入多题。
6. 面试路线额外检查：必须使用简答表达与评价标准，不能退化成字母选择题。
7. 对题库主链路再做浏览器操作，验证入库、去重、状态、Markdown、掌握记录与响应式布局。

## 本轮发现并修复的问题

- 完整讲解超过默认 900 token 后 JSON 被截断：面试讲解预算提高到 2400 tokens，并增加 API 回归测试。
- DeepSeek 的评分标准可能返回嵌套对象：现在无损压平成可存储条目，同时继续拒绝损坏 JSON。
- 模型返回的一道复合追问可能含两个问号：现在只对用户整段粘贴做分题，模型明确返回的每条关联题保持为一个原子题目。
- 画像评分器把陈述句“你学过一点”误认成摸底问题、把“两个连带规则”误认成两道题：已通过句级问号识别和更严格的批量题表达修复，并新增回归测试。

## 尚未扩大范围的事项

- 本轮不推送 GitHub、不创建 PR。
- 自动拓展题仅保存在当前用户个人题库并标记为草稿，不自动发布到共享知识库。
- 浏览器关闭后的系统提醒沿用现有本地后台通知；面向公网多用户部署时，仍需接入 Web Push 或原生桌面通知服务。
